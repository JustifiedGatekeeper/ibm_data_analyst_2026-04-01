# IBM Data Analyst Capstone Project
**Date:** June 2026  

Welcome to my final capstone repository for the IBM Data Analyst Professional Certificate. This repository contains all the required lab notebooks demonstrating data collection, wrangling, and exploratory data analysis, as well as my final presentation and interactive dashboard.  

This project fulfills the capstone technical requirements through the following applied techniques:
* **Data Collection:** Extracted data via APIs and performed web scraping using BeautifulSoup and HTTP requests.  
* **Data Wrangling:** Cleaned data using Pandas by dropping duplicates and filling missing values. Normalized highly skewed fields (such as compensation and experience) using Min-Max scaling, Z-scores, and log transformations to prevent extreme outliers from skewing the final analysis.  
* **Exploratory Data Analysis (EDA):** Removed extreme outliers utilizing IQR and standard deviation thresholds. Visualized data distributions using histograms, KDE plots, box plots, and heatmaps. Mapped statistical relationships using Pearson and Spearman correlation tests.  
* **Data Visualization & Reporting:** Transitioned analysis from Jupyter Notebooks to Google Looker Studio to build an interactive dashboard.

## Findings
The final presentation presents the following findings:  
* **The Python Paradox:** Despite Python being the most sought-after language for future projects, current practitioners report lower levels of job satisfaction compared to peers using other technologies.
* **The Database Dilemma:** Data indicates that developers derive higher job satisfaction from stable, enterprise-grade systems like Microsoft SQL Server than from currently trending alternatives like MongoDB.
* **Industry Shifts:** The talent landscape is defined by a young, highly credentialed workforce that is increasingly prioritizing open-source, cloud-native architectures such as PostgreSQL and AWS.
